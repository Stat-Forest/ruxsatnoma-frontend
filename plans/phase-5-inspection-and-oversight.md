# Фаза 5 — Инспектор и надзор

> **Для агентов:** используйте `superpowers:subagent-driven-development` или `superpowers:executing-plans`.

**Цель:** инспектор составляет акт в поле без связи, прокурор входит через ИМУТ и видит только свою территорию, риск-индикаторы уходят в Генпрокуратуру за пять минут.

**Архитектура:** модуль `inspection` в `core`, модуль `prosecutor` в `core` с пулом `read_only`, обмен с «Raqamli nazorat» — в `integration`. Обоснование, почему прокурор не отдельный сервис, — [`../architecture/diagrams.md`](../architecture/diagrams.md).

Фаза 3 завершена: разрешения выдаются. Фаза 1 задача 1.12 дала пул `read_only` и RLS.

## Готово, когда

- [ ] Инспектор составляет акт без связи, данные синхронизируются позже
- [ ] Проверка по QR из кэша занимает ≤ 1 секунды
- [ ] Медиа несёт время, GPS, устройство и hash
- [ ] Расстояние до контура считается геодезически
- [ ] Статус «нарушение» автоматически открывает дело
- [ ] Прокурор входит только через ИМУТ, только по ЭЦП или OneID
- [ ] Верификация выполняется при каждом входе и не кэшируется
- [ ] Недоступность «Raqamli nazorat» отказывает во входе
- [ ] Любой изменяющий метод под ролью прокурора даёт `403`
- [ ] Запрос вне территории даёт `403` и `RI-12`
- [ ] Все 15 детекторов срабатывают на своих условиях
- [ ] Критические индикаторы доставляются за 5 минут
- [ ] Недоступность надзорной системы не теряет события
- [ ] Экспорт содержит watermark и пишется в оба журнала
- [ ] Метрика `prosecutor_write_attempts_total` равна нулю
