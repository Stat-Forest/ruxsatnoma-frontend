**О2 закрыт 10 августа.** Доступ к базе действующей системы предоставляется. Переносится **всё**: справочники, вся история заявок, разрешений и платежей. Действующие разрешения переносятся как есть, без пересчёта.

**Параллельной работы двух систем не будет** — переход одномоментный. Это меняет цену ошибки: сверка (задача 7.6) становится условием переключения, а не отчётной формальностью. Отката к старой системе после переключения нет.

## Задача 7.1 — Справочники

- [ ] **Шаг 1: Тест — повторный запуск не создаёт дублей**

```python
async def test_migration_is_idempotent(session: AsyncSession) -> None:
    await migrate_organizations(session)
    first = await count_organizations(session)

    await migrate_organizations(session)

    assert await count_organizations(session) == first
```

Проверяется по `legacy_id`. Идемпотентность — условие того, что скрипт можно прогонять сколько угодно раз при разборе расхождений.

```python
async def test_migrated_permit_verifies_by_qr(client: AsyncClient) -> None:
    permit_record = await migrate_active_permit(legacy_id=1024)

    response = await client.get(
        f"/public/v1/permits/verify?series={permit_record.series}&number={permit_record.number}"

    assert response.status_code == 200
    assert response.json()["data"]["status"] == "ACTIVE"
```
