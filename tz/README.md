# ТЗ «Ruxsatnoma-urmon.uz» — разобранная версия

Полный разбор нового технического задания (`../ruxsatnoma-new-tz.docx`, 52 листа, узбекская кириллица, действует с 1 августа 2026) в структурированном виде. Цель — чтобы к исходному `.docx` больше не приходилось возвращаться.

## Соглашения

- Оригинальные узбекские термины сохранены в скобках, когда это идентификатор или юридический термин: «условная голова (шартли бош, СБ)».
- Статусы, коды ошибок и коды риск-индикаторов приведены **как в ТЗ**, латиницей: `SUBMITTED`, `ERR-GIS-001`, `RI-04`.
- Ссылки на НПА даны в узбекской форме, принятой в ТЗ: ВМҚ 689-сон = постановление Кабинета Министров № 689.
