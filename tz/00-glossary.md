# Термины и сокращения

Раздел «Атамалар ва қисқартмалар» оригинала, 36 позиций. Приведены полностью.

| № | Сокращение / термин | Определение |
|---|---|---|
| 1 | **АТ** (Ахборот тизими) | Информационная система |
| 2 | **ЎХ** (Ўрмон хўжалиги) | Лесное хозяйство |
| 3 | **Агентство** | Агентство по увеличению лесов и зелёных зон, борьбе с опустыниванием |
| 4 | **ТТ** (Техник топшириқ) | Техническое задание |
| 5 | **ЭРИ** (Электрон рақамли имзо) | Электронная цифровая подпись, ЭЦП |
| 6 | **CRL / OCSP** | Список отозванных сертификатов ЭЦП / протокол онлайн-проверки статуса сертификата |
| 7 | **БҲМ** | Базовая расчётная величина |
| 8 | **GIS** | Геоинформационная система |
| 9 | **Контур / субконтур** | Геометрия участка лесного фонда с уникальным идентификатором в GIS-реестре и выделенная внутри неё субгеометрия |
| 10 | **Rule engine** | Сервис, исполняющий версионированные правила тарифов, норм, сезонов, ротаций, ограничений и статусов |
| 11 | **Условная голова (шартли бош, СБ)** | Результат приведения разных видов скота к единой учётной единице согласно ВМҚ 689-сон |
| 12 | **SLA / RPO / RTO** | Уровень обслуживания / допустимый период потери данных / целевое время восстановления |
| 13 | **UAT** | Приёмочное тестирование пользователем |
| 14 | **PWA** | Веб-приложение, работающее на мобильном устройстве через браузер, с возможностью offline |
| 15 | **Цифровой надзор (рақамли назорат)** | Функция мониторинга действий должностных лиц в госИС в реальном времени, выявления риск-индикаторов и передачи данных в органы прокуратуры, согласно ПФ-204-сон |
| 16 | **«Raqamli nazorat» АТ (RN)** | Информационная система цифрового надзора Генеральной прокуратуры Республики Узбекистан |
| 17 | **ЖШШИР** | Персональный идентификационный номер физического лица (PINFL) |
| 18 | **СТИР** | Идентификационный номер налогоплательщика (ИНН) |
| 19 | **ИМУТ** | Межведомственная сеть передачи данных |
| 20 | **Read-Only режим** | Режим, в котором доступны только просмотр, поиск, фильтрация, анализ и формирование отчётов; создание, изменение, удаление и смена статуса невозможны **на уровне приложения, API и СУБД** |
| 21 | **ID системы / ресурса** | Единый идентификатор информационной системы или ресурса, зарегистрированного в «Raqamli nazorat» |
| 22 | **Риск-индикатор** | Автоматически выявляемое системой событие, указывающее на вероятность коррупции или нарушения |
| 23 | **Метаданные** | Технические сведения о том, кем, когда, с какого IP/устройства и на каком основании создана или изменена запись |
| 24 | **МББТ** | Система управления базами данных (СУБД) |
| 25 | **RBAC / ABAC** | Модель контроля доступа на основе ролей / на основе атрибутов |
| 26 | **IAM** | Подсистема идентификации, аутентификации и контроля доступа |
| 27 | **Maker-checker** | Двухступенчатый контроль: один сотрудник вводит, второй (с более высокими полномочиями) подтверждает |
| 28 | **Idempotency-Key** | Уникальный ключ, исключающий двойное выполнение повторного запроса |
| 29 | **Outbox / DLQ** | Очередь надёжной доставки / очередь недоставленных сообщений (Dead Letter Queue) |
| 30 | **PITR** | Восстановление базы данных на любой момент времени (Point-In-Time Recovery) |
| 31 | **k-anonymity** | Правило агрегации, исключающее возможность идентификации личности в открытой статистике |
| 32 | **Immutable snapshot** | Неизменяемая копия документа, сохраняющая состояние на момент подписания |
| 33 | **WORM / append-only** | Режим журнала: запись один раз, без возможности удаления и изменения |
| 34 | **Лесной билет (ўрмон чиптаси)** | Документ, дающий право на выполнение работ и пользование в лесу, согласно ВМҚ 506-сон |
| 35 | **НСИ** | Нормативно-справочная информация (классификаторы и справочники) |
| 36 | **BFF** | Backend for Frontend — слой интеграции, адаптированный под внешний канал (my.gov.uz) |
